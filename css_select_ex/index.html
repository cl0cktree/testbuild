CSS 속성 선택자 & 명시도 가이드

서브스트링 매칭 속성 선택자 명세

HTML 요소 내 특정 속성값 문자열 조각(서브스트링)의 일치 패턴을 감지하여 노드를 바인딩합니다.

형식 매칭 메커니즘 패턴 명칭
[class^="val"] 지정한 문자열로 시작하는 요소 Prefix Match
[class$="val"] 지정한 문자열로 끝나는 요소 Suffix Match
[class*="val"] 지정한 문자열이 일부분 포함된 요소 Substring Match
[class~="val"] 공백으로 분리된 독립형 단어 일치 Word Match
[class|="val"] 접두사 단독 혹은 하이픈(-) 연결 시작 Dash Match

실시간 매칭 분석 엔진

클래스명을 입력하면 조건부 스캔을 거쳐 일치하는 정밀 속성 바인더를 추적합니다.

<div id="target" class="..." />
[^="btn"] 접두사 [$="action"] 접미사 [*="act"] 포함 [~="active"] 단어 [|="btn"] 대시

우선순위 명시도(Specificity)

속성 선택자의 가중치 점수는 클래스 선택자 데이터와 완벽히 동등하게 연산됩니다.

속성/클래스 선택자 [class*="btn"] 10 점
태그 결합 선택자 button[class*="btn"] 11 점

동일한 명시도 점수를 가질 경우, 컴파일 트리상에서 하단(나중에) 선언된 스타일이 우선 적용권을 가집니다.

프로덕션 참조 소스 레포지토리

실무 환경의 파일 확장자 감지 모듈 아키텍처 예시 데이터 포맷 구성입니다.

/* 대소문자 무시 식별 스위치(i 플래그) 내장 매칭 아키텍처 */
a[href$=".pdf" i] {
  padding-left: 24px;
  background: url('icon-pdf.svg') no-repeat left center;
}

/* 외부 인바운드 링크 타겟 스크리닝 연산 처리 */
a[href^="https://"]:not([href*="internal.com"]) {
  color: var(--accent);
}
